For this assignment, I used a stack to implement the undo and redo system because a stack follows the Last In, First Out (LIFO) principle. This means the most recent action is the first action that can be undone. For example, if I add three actions, the third action will be removed first when I choose undo. I also used a second stack for redo actions. When an action is undone, it is moved to the redo stack so it can be restored if needed.

For the help desk ticketing system, I used a queue because a queue follows the First In, First Out (FIFO) principle. This means the customer who arrives first should be helped first. The queue keeps customers in the correct order and prevents a newer customer from being helped before someone who has already been waiting.

My stack and queue implementations are different from using Python lists because I created them using linked nodes. Each node stores a value and a reference to the next node. With a Python list, built-in methods can be used to add and remove items directly. In this assignment, I had to create the push, pop, peek, enqueue, dequeue, and print operations myself. This helped me understand how stacks and queues work internally instead of relying on Python's built-in list features.
